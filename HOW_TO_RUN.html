System Startup & Execution Guide

Complete instructions for running the unified Next.js full-stack platform, databases, and AI pipelines

1. System Architecture

The application is built on a unified full-stack architecture using Next.js 14 App Router. Both frontend and backend run together under a single process on port 3000.

Architecture Map
Unified Next.js App (Port 3000)
 ├── FRONTEND: Landing Page (/), Student (/student/*), Admin (/admin/*), Recruiter (/recruiter/*)
 ├── BACKEND: REST API Routes (/api/*), Auth & JWTs, 8 AI Agents
 ├── PostgreSQL: Primary Relational Source of Truth (Prisma ORM)
 ├── MongoDB: Flexible Documents (Resumes, JDs, Transcripts, Agent Runs)
 └── ChromaDB: Semantic Vector Knowledge Store (Dense Embeddings)

2. Quick Start in 4 Commands

bash
# 1. Install dependencies
npm install

# 2. Push database schema & generate Prisma client
npm run prisma:push
npm run prisma:generate

# 3. Seed database with Admin, Recruiters, Students, Jobs, Questions, and Embeddings
npm run seed

# 4. Start Full-Stack Server (Frontend + Backend)
npm run dev

Open your browser at: http://localhost:3000

3. Production Build & Execution

bash
# Compile production bundle
npm run build

# Start production server
npm run start

4. System Verification Suite

bash
npm run verify

Executes 21 end-to-end integration tests verifying PostgreSQL models, MongoDB documents, ChromaDB vector queries, authentication, Zod schemas, and live matching agent execution.
